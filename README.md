# 🌸 CycleFlow + AI 
**A smart, aesthetic period tracker powered by Google Gemini AI.**

CycleFlow is a full-stack web application designed to help users track their cycles while receiving personalized, AI-generated health and wellness insights based on their current mood and symptoms.

## ✨ Features
* **Cycle Tracking:** Input your last period date and cycle length to stay organized.
* **Mood Integration:** Select your current mood (Happy, Sad, Tired, etc.) to get contextual advice.
* **Gemini AI Insights:** A custom Flask backend connects to Google's Gemini 1.5 Flash model to provide smart wellness tips and "notes to self."
* **Aesthetic UI:** A carefully designed, "pink-themed" interface built for a seamless user experience.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Flexbox), and JavaScript (ES6+).
* **Backend:** Python 3, Flask, Flask-CORS.
* **AI Integration:** Google Generative AI (Gemini API).
* **Hosting:** GitHub Pages (Frontend) & PythonAnywhere (Backend).
